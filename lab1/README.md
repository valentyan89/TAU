# Лабораторная 1. Характеристики линейных звеньев

Скрипт строит графики для четырёх звеньев (вариант 10: \(k = 1\), \(T = 0.9\), \(\zeta = 0.4\)):

| Тип | `link_type` | Передаточная функция | Графики |
| --- | --- | --- | --- |
| Апериодическое | `aperiodic` | \(W(s) = k / (Ts + 1)\) | переходная, АФХ, ЛАЧХ, ЛФЧХ |
| Форсирующее | `forcing` | \(W(s) = k(Ts + 1)\) | АФХ, ЛАЧХ, ЛФЧХ (переходной нет) |
| Колебательное | `oscillatory` | \(W(s) = k / (T^2 s^2 + 2\zeta T s + 1)\) | переходная, АФХ, ЛАЧХ, ЛФЧХ |
| Комбинированное | `combined` | \(W(s) = k(2Ts + 1) / [(T^2 s^2 + 2\zeta T s + 1)(Ts + 1)]\) | переходная, АФХ, ЛАЧХ, ЛФЧХ |

## Запуск

Из корня репозитория:

```bash
python lab1/lab1.py
```

Нужны `numpy`, `matplotlib`, `scipy`.

## Параметры: число или список

У каждого звена можно задать `k`, `T`, `zeta` одним числом или списком.

- **Первое значение** — ваш вариант. На графике это **сплошная** кривая.
- **Остальные** — для сравнения. Они рисуются **пунктиром**.

```python
Link(
    name="Апериодическое звено",
    link_type="aperiodic",
    k=1,                 # только вариант
    T=[0.9, 0.45, 1.8],  # 0.9 — вариант, 0.45 и 1.8 — сравнение
)
```

Если списков несколько, каждый параметр меняется **отдельно**, остальные остаются как в варианте. Не строится полный перебор всех комбинаций.

```python
Link(
    name="Колебательное звено",
    link_type="oscillatory",
    k=[1, 0.5],          # кривые: вариант и k=0.5 (T и ζ как в варианте)
    T=0.9,
    zeta=[0.4, 0.15, 0.8],  # плюс кривые ζ=0.15 и ζ=0.8 (k и T как в варианте)
)
```

В легенде у основной линии подписан весь набор параметров варианта, у пунктирных — только изменённый параметр.

## Что сейчас в `lab1.py`

В блоке `if __name__ == "__main__"`:

- апериодическое и форсирующее: сравнение по постоянной времени \(T = 0.9,\; 0.45,\; 1.8\);
- колебательное и комбинированное: сравнение по демпфированию \(\zeta = 0.4,\; 0.15,\; 0.8\).

Чтобы убрать сравнение, передайте одно число, например `T=0.9`.
