# Лабораторная работа № 5

Синтез и анализ непрерывных систем управления максимальной степени устойчивости.

## Запуск в Python

В начале `lab5.py` задайте `VARIANT` числом от 1 до 10. По умолчанию выбран вариант 10. Коэффициенты объекта подставляются из таблицы 5.1 методических указаний.

```powershell
python -m pip install numpy scipy matplotlib
python lab5/lab5.py
```

Команды выполняются из корня проекта. Скрипт сохраняет таблицу `experiments.csv` и три PNG в папку `lab5/results`, затем показывает графики в трёх окнах Matplotlib. В таблице записаны коэффициенты регулятора, корни, степень устойчивости, степень колебательности, установившийся выход, установившаяся ошибка, время регулирования и перерегулирование.

## Условия моделирования

Для объекта с единичной отрицательной обратной связью рассчитываются три серии. В сериях с ПД и с ПИД при β = 0 используются ω = 2,5k и k = 0, 1, 2, 3, 5, 7, 10. Для ПИД при β = ω используются те же значения k, начиная с 1.

Время регулирования определяется по последнему входу в полосу шириной ±5% от модуля установившегося выхода. Перерегулирование считается в направлении установившегося выхода. При отрицательном выходе используется минимум переходной характеристики.

## Структура кода

`ControlSystem` синтезирует регуляторы, `StepResponse` рассчитывает переходные характеристики, а `SystemPlotter` строит графики. Параметры, возвращаемые значения и назначение методов описаны в самом `lab5.py`.

## Столбцы experiments.csv

Одна строка соответствует одному опыту. Показатели рассчитаны для единичного скачка задания при нулевых начальных условиях.

- `variant` — номер варианта из таблицы 5.1.
- `series` — серия опытов. Значение `pd` означает ПД-регулятор, `pid_beta0` — ПИД при β = 0, `pid_equal` — ПИД при β = ω.
- `k` — безразмерный множитель из задания, по которому выбирается ω = 2,5k.
- `omega` — свободный параметр ω, задающий мнимую часть первой пары полюсов, рад/с.
- `beta` — свободный параметр β, задающий мнимую часть второй пары полюсов ПИД, рад/с. Для ПД записывается 0.
- `kp` — пропорциональный коэффициент kп.
- `kd` — дифференциальный коэффициент kд.
- `ki` — интегральный коэффициент kи. Для ПД равен 0.
- `eta` — степень устойчивости η = −max(Re(sᵢ)), с⁻¹. Характеризует скорость затухания наиболее медленной экспоненциальной составляющей.
- `mu` — степень колебательности μ = max(|Im(sᵢ)/Re(sᵢ)|), безразмерная. Характеризует соотношение частоты собственных колебаний и скорости затухания.
- `poles` — полюса замкнутой системы с учётом кратности, с⁻¹. Записаны в виде `a+bj`, где `a` — действительная часть, `b` — мнимая, `j² = −1`. Внутри ячейки полюса разделены точкой с запятой.
- `y_inf` — установившийся выход h∞ = T(0) при единичном задании.
- `e_inf` — установившаяся ошибка e∞ = 1 − h∞. Единицы совпадают с единицами нормированных задания и выхода.
- `ts_s` — время регулирования tр, с. После этого момента выход остаётся в полосе ±5% от модуля h∞ вокруг h∞.
- `overshoot_pct` — перерегулирование σ, %. При положительном h∞ равно 100 · (hmax − h∞)/h∞. Для отрицательного h∞ выброс измеряется в направлении установившегося выхода.

Коэффициенты используются в законе u(t) = kп·e(t) + kд·de/dt + kи·∫e(t)dt. Если отношение единиц управления к единицам ошибки обозначить U/E, размерности коэффициентов составят U/E для kп, (U/E)·с для kд и (U/E)/с для kи.

В CSV разделитель столбцов — запятая, десятичный разделитель — точка. Значение `8.96e-05` означает 8,96 · 10⁻⁵.
