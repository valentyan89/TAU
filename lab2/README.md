# Лабораторная 2. Исследование устойчивости линейных и непрерывных САУ

Скрипт строит гадографы для различных регуляторов

| Тип регулятора| Передаточная функция |
| --- | --- |
| Пропорциональный | $W_p(s) = k_p$ |
| пропорционально-дифференциальный | $W_p(s) = k_p + k_ds$ |
| пропорционально-интегральный | $W_p(s) = k_p + \frac{k_i}{s}$ | 

Передаточная функция объекта управления: $W_o = \frac{1}{a_0s^3 + a_1s^2 + a_2s + 1}$

## Запуск

Из корня репозитория:

```bash
python lab2/lab2.py
```

Нужны `numpy`, `matplotlib`, `scipy`.

## Параметры

Для всех регуляторов задаются универсальные параметры $a_0, a_1, a_2$, значения которых находятся в таблице 2.1, и распределяются согласно варианту

Параметры k подбераются для каждого регулятора. 

$k_э$ означает подобрать эксперементально значение, при котором гадограф будет пересекать точку (-1, 0). Проверить, что значение подобрано правильно можно визуально, или по запасу устойчивости (при этом значении она должна быть ≈ 0)

$k_т$ означает значение параметра из таблицы 2.1 согласно варианту

| Тип регулятора | $k_p$ | $k_d$ | $k_i$ |
| --- | --- | --- | --- |
| Пропорциональный | [1, $k_э$, 4] |  |  |
| пропорционально-дифференциальный | 4 | [$k_т, k_э, k_т + 2(k_э - k_т)$] |  |
| пропорционально-интегральный | 1 |  | [$k_т, k_э, k_т + 2(k_э - k_т)$] |

## Вывод графиков

При иследовании на устойчивость рекомендуют строить отражённые относительно действительной оси гадографы, для лучшего определения пересечения точки (-1, 0), однако в методических материалах про это не сказанно. Чтобы оключить построение отражённых гадографов в блоке `if __name__ == "__main__"` при инициализации объекта класса `SystemPlotter` укажите `SystemPlotter(mirror=False)`

## Вывод анализа регуляторов
Вывод анализа производится в консоль. Анализ содержит:
- Нахождение корней характеристического уравнения
- Определение состояния системы
- Нахождение запаса устойчивости при различных k параметров 

## Что сейчас в `lab2.py`

В блоке `if __name__ == "__main__"` решение лабораторной для значений из **1 варианта**. Решение включает в себя следующий анализ для каждого из регуляторов и построение его гадографа.
