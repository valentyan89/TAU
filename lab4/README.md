# Лабораторная 4. Метод коэффициентов ошибки

Вариант 10. Цель: исследовать точность САУ в установившемся режиме методом коэффициентов ошибки (МКО). Реализация на Python, NumPy, SciPy и Matplotlib по аналогии с lab1–lab3.

## Задание

Собрать систему с П-регулятором и тремя апериодическими звеньями; определить ошибки по заданию и возмущению для шести негармонических и пяти гармонических опытов из таблиц 4.2–4.3. Сравнить моделирование с расчётом. Поочерёдно добавить интегратор в регулятор и объект, исследовать повышение порядка астатизма и проверить устойчивость.

## Исходные данные и модель

По таблице 4.1: k₁=4, k₂=1, k₃=1; T₁=1 с, T₂=0.8 с, T₃=0.04 с.

$$W_o(s)=\frac{4}{(s+1)(0.8s+1)(0.04s+1)}=\frac4{D(s)},$$
$$D(s)=0.032s^3+0.872s^2+1.84s+1.$$

Методичка не задаёт численные значения усиления П-регулятора и амплитуды A: для основных опытов приняты kп=1 и A=1. Все начальные условия нулевые.

![Структурная схема](results/structure.png)

По рис. 4.1 помеха складывается с управлением перед объектом: y=Wo(Wp·e+f), e=g−y. Поэтому полная знаковая ошибка **e=eg−ef**. Здесь eg измеряется при f=0, а положительный канал ef=−e при g=0 соответствует формуле Wfe из методички. Таблицы содержат отдельные каналы, не их сумму.

$$W_{ge}=\frac{D}{D+4},\qquad W_{fe}=\frac4{D+4}.$$

Корни характеристического уравнения: −25.215394; −1.017303 ± j2.271939. Система устойчива.

## Расчёт методом коэффициентов ошибки

$$C_m=W_e^{(m)}(0),\qquad e_{уст}=C_0u+C_1\dot u+\frac{C_2}{2}\ddot u+\ldots.$$

Важно: C₂ — вторая производная передаточной функции, поэтому в формуле ошибки присутствует деление на 2. Коэффициенты вычисляются рекурсивным делением полиномов в окрестности s=0.

| Канал | C₀ | C₁ | C₂ |
| --- | ---: | ---: | ---: |
| По заданию | 0.2 | 0.2944 | 0.0623616 |
| По помехе | 0.8 | −0.2944 | −0.0623616 |

Для постоянного u=a: eуст=aC₀. Для линейного u=at: eуст=a(C₀t+C₁). Это установившаяся составляющая ошибки после затухания переходного процесса; при C₀≠0 и линейном входе конечного предела ошибки нет.

## Таблица 4.3. Гармонические воздействия

Для u=A sin(ωt) установившаяся ошибка периодична:

$$e_{уст}(t)=B\sin(\omega t+\varphi),\quad B=A|W_e(j\omega)|,\quad\varphi=\arg W_e(j\omega).$$

Предел e(t) здесь не существует. Экспериментальные B и φ определены методом наименьших квадратов по последним десяти периодам. Точный частотный расчёт сопоставлен с МКО по первым трём коэффициентам:

$$W_e(j\omega)\approx C_0+j\omega C_1-\frac{\omega^2 C_2}{2}.$$

## Влияние интеграторов

Для опытов с одним интегратором выбрано kп=0.05. Это отдельная настройка для обеспечения устойчивости; сравнение численной величины ошибки с П-регулятором зависит также от изменения усиления. Обе схемы с одним интегратором сравниваются при одинаковом kп.

Если nc и no — числа интеграторов в регуляторе и объекте, то:

$$W_{ge}=\frac{s^{nc+no}D}{s^{nc+no}D+4k_п},\qquad W_{fe}=\frac{4s^{nc}}{s^{nc+no}D+4k_п}.$$

| Система | C₀g | C₁g | C₂g | C₀f | C₁f | C₂f |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Интегратор в регуляторе | 0 | 5 | −31.6 | 0 | 20 | −200 |
| Интегратор в объекте | 0 | 5 | −31.6 | 20 | −100 | 632 |

Обе схемы устойчивы: полюса −24.999561, −1.557238, −0.346600 ± j0.201027. Для каждого случая повторены все опыты таблиц 4.2–4.3; результаты находятся в CSV с суффиксами `I_controller` и `I_plant`.

Для постоянного задания обе схемы дают eg→0; для g=at обе дают eg→5a. При интеграторе в регуляторе постоянная помеха подавляется, для f=at остаётся ef→20a. При интеграторе в объекте постоянная помеха даёт ef→20f, а линейная — ef≈20at−100a. Место интегратора не меняет канал по заданию при одинаковом произведении WpWo, но меняет канал по помехе.

Два чистых интегратора (в регуляторе либо объекте) при kп=0.05 дают полюса 0.114408 ± j0.369891 в правой полуплоскости. Такие системы неустойчивы; установившиеся ошибки им не приписываются. Формального увеличения астатизма недостаточно: требуется коррекция регулятора с проверкой устойчивости.

## Выводы и ответы на дополнительные вопросы

1. МКО использует разложение передаточной функции ошибки около s=0 и производные входного воздействия. Он описывает установившуюся составляющую только при затухании собственных процессов системы.
2. Ошибка зависит от структуры и параметров САУ, места приложения помехи, типа, амплитуды и частоты воздействий. Для линейной системы увеличение амплитуды в 5 или 10 раз увеличивает соответствующую ошибку во столько же раз.
3. C₀ характеризует ошибку по положению; C₁ — по скорости; C₂ — по ускорению. Для параболического входа u=at²/2 вклад ускорения равен aC₂/2 при принятом определении коэффициентов как производных.
4. Статическая система имеет ненулевой C₀. Астатическая относительно выбранного канала имеет нули передаточной функции ошибки при s=0 и отслеживает постоянный вход этого канала без установившейся ошибки.
5. Интегратор в регуляторе обеспечивает астатизм первого порядка по заданию и входной помехе. Интегратор в объекте обеспечивает его по заданию, но не по помехе перед объектом. Увеличение порядка требует повторной проверки устойчивости.
6. При ω=50 рад/с объект сильно ослабляет помеху, но ошибка слежения по заданию близка по амплитуде к самому заданию. Ряд МКО из трёх членов на этой частоте даёт большую погрешность; точный расчёт гармоник проводится по W(jω).

## Проверка результатов

Скрипт проверяет корни характеристических полиномов. Для негармонических воздействий он сравнивает моделирование SciPy с МКО на последних 20% адаптированного интервала. Для гармоник независимо сопоставляет оценку амплитуды и фазы из временного отклика с частотной передаточной функцией. Начальная часть моделирования продолжается не менее 30 постоянных времени самого медленного полюса.
