# Лабораторная № 4, вариант 10

Метод коэффициентов ошибки. Объект `4/((s+1)(0.8s+1)(0.04s+1))`.

Запуск из корня проекта:

```powershell
python -m pip install -r lab4/requirements.txt
python lab4/lab4.py
```

Коэффициент регулятора `kp` и амплитуда гармоник `amplitude` заданы в блоке запуска.
Программа печатает результаты опытов по таблицам 4.2 и 4.3 и открывает графики.
